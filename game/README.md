# ردع العدوان — لعبة رماية صواريخ التاو

لعبة ثلاثية الأبعاد في المتصفح (three.js) مستوحاة من معركة «ردع العدوان» بين 27 تشرين الثاني و8 كانون الأول 2024: أنت رامي صواريخ تاو، تتقدّم مع المحاور من الفوج 46 في ريف حلب الغربي حتى دمشق.

كل الرسوميات والأصوات مولّدة إجرائياً في الكود: لا صور ولا ملفات صوت خارجية.

## التشغيل

```bash
cd game
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

تُحمَّل مكتبة three.js من CDN عبر importmap، فيلزم اتصال بالإنترنت عند أول تشغيل. بعدها يخزّن عامل الخدمة (sw.js) الملفات للعب دون اتصال عند الاستضافة على https.

### نسخة بملف واحد (دون CDN)

```bash
cd game
npm install
npm run build              # ينتج dist/rada3.html
node build.mjs --artifact  # نسخة لصفحات Claude Artifacts
```

### النشر على GitHub Pages

فعّل Pages للمستودع واختر المجلد الجذر، ثم افتح `https://<user>.github.io/<repo>/game/`. ضع الرابط في `shareUrl` داخل `src/config.js` ليظهر في رسائل المشاركة.

## المحتوى

- **10 محاور و30 مهمة:** الفوج 46، سراقب، حلب، خان شيخون، حماة (جبل زين العابدين)، الرستن، **تلبيسة**، **تيرمعلة**، حمص، دمشق.
- **أنواع المهمات:** كمين رتل، اقتحام، تدمير مستودع، حماية رتل، دفاع جوي، هدف ثمين (T-90 بتشويش شتورا)، صدّ هجوم الميليشيات، المعركة الأخيرة.
- **4 صعوبات:** سهل، متوسط (ميليشيات إيرانية إضافية ومروحيات)، صعب (**تدخّل الطيران الروسي**: غارات سوخوي Su-24/Su-34 ومروحيات Mi-24)، أسطوري (غارات كثيفة ومسيّرات انتحارية وبلا مؤشرات).
- **الأسلحة:** تاو TOW-2A الموجّه سلكياً (السلاح الأساسي)، رشاش KPV 14.5، إيغلا مضاد للطيران بقفل حراري، مسيّرة شاهين FPV تقودها بنفسك، راجمة صواريخ، وتاو 2B للهجوم العلوي.
- **مؤثرات:** قذف برج الدبابة، حرائق الهياكل ودخانها، شظايا، موجات صدمة، تأخير الصوت حسب المسافة، صمم مؤقت عند الانفجارات القريبة، منظار حراري (أبيض/أسود ساخن)، مطر وغبار وليل.
- **إعادة اللقطة:** بعد كل إصابة قاتلة تُحفظ لقطة سينمائية (كاميرا تلاحق الصاروخ، تبطيء لحظة الإصابة، دوران حول الانفجار)، ويمكن تسجيلها فيديو ومشاركتها على واتساب.
- **التحكم:** سحب بالإصبع، عصا توجيه، أزرار أسهم، **دوران الجهاز (جيروسكوب)**، فأرة ولوحة مفاتيح، ويد تحكم.

## الشراء عبر المعرّف (UUID) وواتساب

1. لكل جهاز معرّف فريد يظهر في: المتجر ← مميز.
2. «اطلب عبر واتساب» يفتح محادثة برسالة جاهزة فيها المنتج والمعرّف ورقم الطلب.
3. يولّد البائع كود التفعيل ويرسله، فيُدخله اللاعب في خانة التفعيل.
4. «إهداء لصديق» يرسل الطلب بمعرّف الصديق ورمز منتج ينتهي بـ `@gift` ورقم طلب عشوائي (1000-9999)، ويعمل الكود على جهاز الصديق فقط.
5. يمكن لصق رسالة البائع كاملة في خانة الكود؛ اللعبة تستخرج الكود منها.

### إعدادات البائع (`src/config.js`)

```js
whatsappNumber: '963912345678', // رقمك بالصيغة الدولية بلا + أو أصفار
shopSecret: 'غيّر-هذا-المفتاح',  // غيّره، وضع القيمة نفسها في أداة التوليد
shareUrl: 'https://…/game/',     // رابط اللعبة في رسائل المشاركة
```

### توليد الأكواد

- صفحة: `tools/keygen.html`. افتحها محلياً عبر الخادم والصق رسالة الطلب كاملة في حقل المعرّف ليُملأ المنتج ورقم الطلب تلقائياً.
- سطر الأوامر: `python3 tools/keygen.py <UUID> <ITEM_ID> [ORDER_NO] --secret <SECRET>` (للهدايا: `gold_5k@gift` مع رقم الطلب من الرسالة)

المنتجات: `gold_5k`، `gold_25k`، `tow2b`، `unlock_all`، `vip`، `skin_gold`.

> التحقق من الأكواد يتم داخل المتصفح، لذا يمكن لمستخدم متمرّس استخراج المفتاح من الكود. للحماية الكاملة يلزم خادم تحقق، وهذا خارج نطاق النسخة الحالية.

## الباقة الهدية

- هدية ترحيب مرة واحدة: 1,500 ذهب وصاروخ إيغلا مجاناً.
- هدية يومية تكبر مع الأيام المتتالية حتى اليوم السابع.
- إهداء المنتجات المميزة لصديق عبر معرّفه، ودعوة الرفاق برابط واتساب.

## بنية الكود

```
src/core     أدوات، ضجيج، حفظ، متجر، أكواد
src/data     الأسلحة والوحدات والصعوبات، المناطق والمهمات
src/engine   التضاريس، المباني، النماذج، الجسيمات، المؤثرات، السماء، الحراري، الصوت، المعالجة اللاحقة
src/game     العالم، الوحدات وذكاؤها، المقذوفات، اللاعب، المهمة، إعادة اللقطة
src/ui       الإدخال، واجهة القتال، القوائم
tools        مولّد أكواد التفعيل
```
