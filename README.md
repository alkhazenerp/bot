# Telegram Crypto Bot 🤖

بوت تليغرام للاستثمار الخيري في العملات الرقمية.

## المميزات
- دعم multiple cryptocurrencies
- واجهة سهلة الاستخدام  
- يعمل 24/7 على السحابة

## التنصيب
1. انسخ المستودع
2. اضبط متغيرات البيئة
3. انشر على Render

## لعبة «ردع العدوان»

لعبة رماية صواريخ تاو ثلاثية الأبعاد في المتصفح داخل المجلد [`game/`](game/README.md): 10 محاور من الفوج 46 حتى دمشق (منها تلبيسة وتيرمعلة)، 30 مهمة، 4 صعوبات يتدخل فيها الطيران الروسي، وإعادة اللقطة، والشراء بكود مرتبط بالمعرّف عبر واتساب.

```bash
cd game && python3 -m http.server 8080
```
